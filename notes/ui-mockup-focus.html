이번 세션에서 건진 것1장

foldLeft의 초기값 Nil — 타입이 List[Nothing]으로 먼저 고정됨

함정빈 컬렉션 리터럴을 초기값으로 넘기면, 첫 인자 목록에서 누적기 타입 B가 List[Nothing]으로 고정되어 a :: acc가 컴파일되지 않습니다.
해결초기값에서 원소 타입을 명시합니다. List.empty[A] 또는 Nil: List[A].
코드 
xs.foldLeft(Nil)((acc, a) => a :: acc)
xs.foldLeft(List.empty[A])((acc, a) => a :: acc)
