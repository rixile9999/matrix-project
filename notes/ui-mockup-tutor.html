Operator 창 시안

문제 화면 우측에 붙는 질문응답 창입니다. 타이머가 도는 동안은 잠기고, 시간이 끝나면 열립니다. 상태 버튼과 슬라이더는 눌러 볼 수 있고, 대화 내용은 모두 예시입니다.

1. 문제 화면과 Operator 창

세 가지 상태를 바꿔 보세요. Operator에게 넘어가는 정보도 상태마다 다릅니다.

b-08 누적 합기본 · fold·누적1:12

리스트 xs의 모든 원소의 합을 foldLeft로 구한다.

def total(xs: List[Int]): Int =
  xs.foldLeft(0)((acc, x) => acc + x)

아직 실행하지 않았습니다.

치트시트Operator

2. 설명에 쓰는 그림

Operator가 정해진 형식으로 답하면 화면이 그림으로 바꿔 그립니다. 추적 값은 채점기로 실제 실행해 대조하고, 맞으면 "실행 확인됨"을 붙입니다.

구조 그림: for가 풀리는 과정
for a <- xs; b <- ys if a < b yield a + b
↓ 앞 생성기는 flatMap
xs.flatMap(a => for b <- ys if a < b yield a + b)
↓ 가드는 withFilter, 마지막 생성기는 map
xs.flatMap(a => ys.withFilter(b => a < b).map(b => a + b))
코드 비교: 내 코드와 모범답안
내 코드var s = 0 for x <- xs do s += x s
모범답안xs.foldLeft(0)(_ + _)

달라진 줄만 강조합니다. 통과하거나 포기한 뒤에만 나옵니다.

3. 휴대폰: 암기 카드에서 묻기

답이 이미 공개된 화면이라 제한 없이 묻습니다. 아래에서 올라오는 창으로 엽니다.

for에 if 가드를 붙였더니 Either에서 컴파일이 깨진다. 왜인가?

가드는 withFilter 호출로 바뀌는데 Either에는 withFilter가 없다.
그럼 Option은 왜 돼?

Option에는 걸러 낸 결과를 담을 None이 있다. Either는 걸러 냈을 때 Left에 무엇을 넣을지 정할 수 없어서 만들지 않았다.
