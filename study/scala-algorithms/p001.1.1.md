# 맨 앞 양수만 자르기 / Leading positives

정수 배열 `nums`의 맨 앞에서부터 양수가 이어지는 부분만 새 배열로 반환하세요. 0 이하의 수가 처음 나오면 거기서 멈추고, 뒤의 양수는 포함하지 않습니다. `return`은 쓰지 마세요.

Return a new array containing only the leading consecutive positive values from `nums`. Stop at the first non-positive value and do not include later positives. Do not use `return`.

```scala
def leadingPositives(nums: Array[Int]): Array[Int]
```

| 입력 / Input | 반환값 / Return value |
|---|---|
| `Array(4, 2, 0, 8)` | `Array(4, 2)` |
| `Array(-1, 2, 3)` | `Array.empty[Int]` |
| `Array(1, 2, 3)` | `Array(1, 2, 3)` |
| `Array.empty[Int]` | `Array.empty[Int]` |
