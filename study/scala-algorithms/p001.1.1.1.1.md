# `limit` 이상이 될 때까지 2배하기 / Double until at least `limit`

값 `1`에서 시작해 `limit`보다 작은 동안 계속 2를 곱합니다. 처음으로 `limit` 이상이 된 값을 반환하세요. (`limit >= 1`, `return`은 쓰지 마세요.)

Start from `1` and repeatedly double the value while it is less than `limit`. Return the first value that is at least `limit`. (`limit >= 1`, do not use `return`.)

```scala
def firstPowerOfTwoAtLeast(limit: Int): Int
```

| 입력 / Input | 반환값 / Return value |
|---:|---:|
| `1` | `1` |
| `5` | `8` |
| `8` | `8` |
| `10` | `16` |
