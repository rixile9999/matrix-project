# 맨 앞의 연속 양수 / Positive prefix

정수 배열 `nums`의 맨 앞에서부터 양수가 연속으로 몇 개 나오는지 반환하세요. 빈 배열이거나 첫 원소가 0 이하이면 0을 반환하세요.

Return the number of consecutive positive values at the start of the integer array `nums`. Return 0 if the array is empty or its first element is zero or negative.

```scala
def positivePrefixLength(nums: Array[Int]): Int
```

| 입력 / Input | 반환값 / Return value |
|---|---:|
| `Array(4, 2, 0, 8)` | 2 |
| `Array(-1, 2, 3)` | 0 |
| `Array(1, 2, 3)` | 3 |
| `Array.empty[Int]` | 0 |
