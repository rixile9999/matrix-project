# 가장 긴 양수 구간 / Longest positive run

정수 배열 `nums`에서 양수만 연속으로 나오는 가장 긴 구간의 길이를 반환하세요. 0과 음수는 구간을 끊습니다. 빈 배열이거나 양수가 하나도 없으면 0을 반환하세요.

Given an integer array `nums`, return the length of its longest contiguous run of positive values. Zero and negative values break a run. Return 0 if the array is empty or contains no positive values.

```scala
def longestPositiveRun(nums: Array[Int]): Int
```

| 입력 / Input | 반환값 / Return value |
|---|---:|
| `Array(2, 5, 0, 3, 4, 1, -2)` | 3 |
| `Array(-1, 0, -3)` | 0 |
| `Array.empty[Int]` | 0 |

Scala 3로 작성하세요. 배열 길이는 최대 100,000이며, 요구 시간 복잡도는 O(n)입니다.

Use Scala 3. The array has at most 100,000 elements. Your solution must run in O(n) time.
