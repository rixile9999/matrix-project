두 가지 문제가 있다.

1. `acc + x`는 양수의 개수가 아니라 값의 합을 구한다. 실제 실행 결과 `Array(4, 2, 0, 8)`에서 `2` 대신 `6`, `Array(1, 2, 3)`에서 `3` 대신 `6`을 반환했다.
2. `foldLeft` 람다 안의 `return acc`는 Scala 3에서 비지역(non-local) `return` 경고를 낸다(`Non local returns are no longer supported`). `foldLeft`는 배열을 끝까지 순회하는 연산이라 중간에 멈추는(조기 종료) 작업에 맞지 않는다.

`return` 없이 조건이 깨질 때 멈추는 방법을 다루는 하위 문제(`p001.1.1`)를 제안한다. 원하면 `p001.1.answer2.md`로 바로 다시 풀어도 된다.

There are two issues.

1. `acc + x` sums the values instead of counting them. Running your code returns `6` instead of `2` for `Array(4, 2, 0, 8)`, and `6` instead of `3` for `Array(1, 2, 3)`.
2. `return acc` inside a `foldLeft` lambda triggers Scala 3's non-local return warning (`Non local returns are no longer supported`). `foldLeft` always traverses the whole collection and is not meant for early exit.
