아주 근접했지만 딱 **1 모자란(off-by-one)** 실수가 남아 있다:
- `Array(1, 2, 3)` → 기대값 `3`, 실제 반환 `2`
- `Array(2, 0, 3, 4, 5)` → 기대값 `3`, 실제 반환 `2`
- `Array(5)` → 기대값 `1`, 실제 반환 `0`

`else` 분기에서 이번 양수를 포함해 `acc`가 `acc + 1`로 늘어나는데, `lgt`는 늘어나기 **전의 `acc`**와 비교하고 있다. (예: `Array(5)`에서 `i = 0`일 때 `lgt`를 `0`과 비교하고 `acc`만 `1`로 넘겨, 다음 단계 `i == 1`에서 `lgt = 0`이 반환된다.)
