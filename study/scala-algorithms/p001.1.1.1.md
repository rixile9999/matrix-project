# 0 이하가 처음 나오는 위치 / First non-positive index

정수 배열 `nums`에서 0 이하의 수가 처음 나오는 인덱스(0부터 시작)를 반환하세요. 모든 원소가 양수이거나 배열이 비어 있으면 `nums.length`를 반환하세요.

Return the 0-based index of the first element in `nums` that is zero or negative. If all elements are positive or the array is empty, return `nums.length`.

```scala
def firstNonPositiveIndex(nums: Array[Int]): Int
```

| 입력 / Input | 반환값 / Return value |
|---|---|
| `Array(4, 2, 0, 8)` | 2 |
| `Array(-1, 2, 3)` | 0 |
| `Array(1, 2, 3)` | 3 |
| `Array.empty[Int]` | 0 |
