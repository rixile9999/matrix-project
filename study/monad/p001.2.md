# 꺼내기 / Unwrap

`Option[Int]`를 받아서, `Some`이면 안의 값을, `None`이면 `0`을 돌려주는 `unwrap`을 쓰세요. `Option`의 메서드(`getOrElse`, `fold` 등)는 쓰지 말고 `match`로 작성하세요.

Write `unwrap`: given an `Option[Int]`, return the value inside `Some`, or `0` for `None`. Do not use `Option`'s methods (`getOrElse`, `fold`, …); use `match`.

```scala
def unwrap(o: Option[Int]): Int

unwrap(Some(5))  // 5
unwrap(None)     // 0
```

Scala 3.
