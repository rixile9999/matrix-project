# 상자 열기 / Open the box

`case class Box(v: Int)`가 있습니다 (채점 파일에 정의돼 있습니다). `Box`를 받아 안의 값을 돌려주는 `open`을 `match`로 쓰세요.

There is a `case class Box(v: Int)` (defined in the test file). Write `open` with `match`: given a `Box`, return the value inside.

```scala
def open(b: Box): Int

open(Box(7))  // 7
```

Scala 3.
