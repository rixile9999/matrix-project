# p001.2 분석

> ```scala
> def unwrap(o: Option[Int]): Int =
>     o match
>     case Some => o.get
>     case _ => None
> ```

컴파일 에러:

```
[error] 3:10  Found: Some.type  Required: Option[Int]
[error]     case Some => o.get
[error] 4:15  Found: None.type  Required: Int
[error]     case _ => None
```

`case`는 값을 검사하는 동시에 안의 값에 이름을 붙여 꺼내는 자리인데, 그 바인딩 문법을 몰라서 `o.get`으로 우회한 거야.

하위 문제 `p001.2.1`을 냈어.
