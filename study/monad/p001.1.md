# 더하는 함수 만들기 / Make an adder

`n`을 받아서, 받은 수에 `n`을 더하는 **함수**를 돌려주는 `adder`를 쓰세요.

Write `adder`: given `n`, return a **function** that adds `n` to its argument.

```scala
def adder(n: Int): Int => Int

adder(3)(4)   // 7
```

Scala 3.
