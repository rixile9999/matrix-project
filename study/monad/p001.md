# 이어 붙이기 / Chaining

`f`와 `g`는 둘 다 실패할 수 있는 함수입니다. `f`를 먼저, 그 결과로 `g`를 실행하는 함수를 만드세요. 어느 한쪽이라도 실패하면 결과는 `None`입니다.

`f` and `g` are functions that may fail. Build a function that runs `f`, then feeds its result to `g`. If either one fails, the result is `None`.

```scala
def compose[A, B, C](f: A => Option[B], g: B => Option[C]): A => Option[C]
```

```scala
val parse: String => Option[Int]    = _.toIntOption
val recip: Int => Option[Double]    = n => if n == 0 then None else Some(1.0 / n)

compose(parse, recip)("4")  // Some(0.25)
compose(parse, recip)("0")  // None
compose(parse, recip)("x")  // None
```

`Option`의 메서드(`map`, `flatMap`, `getOrElse`, `fold` 등)는 쓰지 말고 `match`로 작성하세요. Scala 3.

Do not use `Option`'s methods (`map`, `flatMap`, `getOrElse`, `fold`, …); use `match`. Scala 3.
